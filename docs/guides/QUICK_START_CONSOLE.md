# Quick Start: Console Terminal Demo

## 🚀 Fastest Way to Demo Your Project

```bash
cd Compiler
python demo_console.py
```

That's it! This will run a complete presentation-ready demo.

---

## What You'll See

1. **Professional header** with project title
2. **Step-by-step analysis** for each expression:
   - Tokenization (breaking into tokens)
   - Language detection
   - Parsing (grammar validation)
   - Statistics
3. **Multiple example expressions** covering different patterns
4. **Clear formatting** perfect for presentations

---

## Other Options

### Interactive Mode (Type Your Own Expressions)
```bash
python demo_console.py interactive
```

### Quick Results (No Pauses)
```bash
python demo_console.py quick
```

### Original Menu
```bash
python main.py
```

---

## Voice Input Note

The web interface has voice input, but it may not work well for:
- Multilingual expressions (French + Pidgin + English)
- Local pronunciations
- Code-mixed words

**Solution**: Use console for demos - it's more reliable and professional!
