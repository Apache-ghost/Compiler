## 📚 File Categories

### Guides (`docs/guides/`)
User-facing guides for using the project:
- **CONSOLE_DEMO_GUIDE.md** - Complete guide for console terminal demonstrations
- **QUICK_START_CONSOLE.md** - Quick start guide for console demo
- **QUICK_START.md** - General quick start guide
- **TEST_WEB_INTERFACE.md** - Guide for testing the web interface
- **VOICE_INPUT_GUIDE.md** - Guide for using voice input feature

### Theory (`docs/theory/`)
Educational and theoretical content:
- **COMPLETE_EDUCATIONAL_GUIDE.md** - Complete guide explaining all compiler concepts
- **PROJECT_EXPLANATION_GUIDE.md** - How to explain and present your project
- **grammar_transformations.md** - Grammar transformations documentation

### Reports (`docs/reports/`)
Analysis reports and summaries:
- **COMPLETION_SUMMARY.md** - Summary of completed work
- **EXPRESSION_ACCEPTANCE_REPORT.md** - Analysis of accepted/rejected expressions
- **FEATURES_SUMMARY.md** - Summary of project features
- **GRAMMAR_ANALYSIS.md** - Detailed grammar analysis
- **VOICE_IMPROVEMENTS_SUMMARY.md** - Summary of voice input improvements

### Checklists (`docs/checklists/`)
Project management:
- **FINAL_CHECKLIST.md** - Final project submission checklist
